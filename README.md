# حُضور — منصة إدارة الحضور للمجموعات

تطبيق Streamlit عربي بواجهة RTL للدكتور لإدارة مجموعات المادة، وإنشاء روابط حضور مؤقتة، واستعراض السجلات والإحصائيات، وتصدير تقرير Word لكل محاضرة.

## الوظائف

- مساحة خاصة للدكتور بكلمة مرور قابلة للضبط.
- مجموعات مستقلة لكل منها جدولها وقائمة طلابها (اسم في كل سطر). يدعم التطبيق قوائم من 20 إلى 45 طالبًا، ويمكن استخدامه لقوائم أخرى.
- رابط عشوائي مستقل لكل محاضرة، صالح افتراضيًا لمدة ساعة، مع خيار 15/30/45/60 دقيقة وإغلاق مبكر.
- واجهة الطالب بالرابط: إدخال الاسم فقط. عند تسجيل قائمة للمجموعة، يجب أن يطابق الاسم أحد الأسماء المسجلة.
- منع تسجيل الاسم مرتين في المحاضرة نفسها، وعدّاد وقت، وتسجيل وقت الحضور.
- سجل المجموعة والمحاضرة، عرض الحاضرين والغياب وفق القائمة، وإحصائيات عامة ورسوم بيانية وتفصيل حسب الطالب.
- تصدير تقرير Word لكل مجموعة ومحاضرة، بأسماء الطلبة وحالة حاضر/غائب، دون تقديرات.
- الخلفية البنفسجية `#702963` والأزرار الذهبية `#FFD700` وتصميم عربي متجاوب.

## تشغيل محليًا عبر VS Code

1. ثبّت Python 3.10 أو أحدث وVS Code.
2. افتح مجلد المشروع في VS Code.
3. أنشئ بيئة افتراضية وافتح الطرفية داخل المجلد:

   ```bash
   python -m venv .venv
   # Windows PowerShell
   .venv\\Scripts\\Activate.ps1
   # macOS/Linux: source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. أنشئ `.streamlit/secrets.toml` (لا ترفع هذا الملف) وأضف:

   ```toml
   DOCTOR_PASSWORD = "استبدلني-بكلمة-مرور-قوية"
   APP_URL = "http://localhost:8501"
   ```

   على Windows أنشئ المجلد `.streamlit` إن لم يكن موجودًا. يوجد نموذج في `secrets.example.toml`.
5. شغّل:

   ```bash
   streamlit run app.py
   ```

   افتح `http://localhost:8501`. قاعدة البيانات `attendance.db` تُنشأ تلقائيًا بجانب التطبيق.

## رفع المشروع إلى GitHub

من مجلد المشروع، أنشئ مستودعًا جديدًا (خاصًا أو عامًا حسب رغبتك) من GitHub، ثم:

```bash
git init
git add app.py requirements.txt README.md .gitignore .streamlit/config.toml secrets.example.toml
git commit -m "Build Arabic attendance management app"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

تأكد من عدم إضافة `.streamlit/secrets.toml` أو `attendance.db` إلى GitHub. ملف `.gitignore` يستثنيهما تلقائيًا.

## نشره على Streamlit Community Cloud

1. افتح [share.streamlit.io](https://share.streamlit.io) وسجّل الدخول بواسطة GitHub.
2. اختر **Create app** وحدد المستودع والفرع `main` وملف `app.py`.
3. من إعدادات التطبيق افتح **Secrets** وأضف:

   ```toml
   DOCTOR_PASSWORD = "كلمة-مرور-قوية-وفريدة"
   APP_URL = "https://اسم-تطبيقك.streamlit.app"
   ```

4. أعد تشغيل التطبيق. ادخل كدكتور، أضف كل مجموعة وأسماء طلابها، ثم أنشئ رابطًا لكل محاضرة وأرسله للمجموعة المقصودة.

## مهم بشأن تخزين البيانات

النسخة الحالية تحفظ البيانات في SQLite داخل `attendance.db` على جهاز تشغيل التطبيق؛ وهي مناسبة للتجربة وعلى جهاز/خادم يحتفظ بالقرص. **التخزين المحلي في Streamlit Community Cloud لا ينبغي اعتباره دائمًا**؛ قد تُفقد قاعدة البيانات عند إعادة إنشاء البيئة أو نقل التطبيق. قبل استخدامه كسجل رسمي دائم، اربط قاعدة البيانات بخدمة دائمة مثل PostgreSQL/Supabase وعدّل موصل التخزين، أو انشره على استضافة ذات قرص دائم، وخذ نسخًا احتياطية دورية.

## حدود التحقق من الهوية

طلب الاسم فقط لا يثبت أن صاحب الهاتف هو الطالب، ولا يمكن لأي واجهة ويب منع انتحال الاسم منعًا كاملًا بهذا الشرط وحده. التحقق من قائمة الأسماء، الرابط العشوائي المحدود الزمن، ومنع التكرار تقلل إساءة الاستخدام لكنها لا تلغيها. لا تشارك رابط المجموعة خارج القناة المخصصة، واستخدم تحققًا إضافيًا (مثل رمز طالب فريد أو تسجيل دخول مؤسسي) إذا كان إثبات الهوية مطلوبًا.

## ملفات المشروع

- `app.py` — التطبيق الكامل والواجهات والمنطق.
- `requirements.txt` — اعتماديات Python.
- `.streamlit/config.toml` — إعدادات المظهر وسلوك Streamlit.
- `secrets.example.toml` — نموذج إعداد الأسرار (انسخه محليًا فقط).
- `.gitignore` — استثناء الأسرار وقاعدة البيانات والبيئة الافتراضية.
